PROJECT OVERVIEW (READ FIRST)

Build a Ward-Wise Pollution Action Dashboard where each administrative ward is the smallest operational unit for pollution monitoring, decision-making, and action.

The system must have two strictly separated roles:

Citizen Interface
Used by residents to view ward-level pollution, receive health advisories, follow prevention measures, plan daily activities using pollution data, and contribute through collective ward-level actions.

Government Authority Interface
Used by officials to monitor pollution across wards, assign responsibility scores, apply ward-specific control techniques, simulate policies, and manage pollution emergencies.

All features must be explicitly ward-wise.
City-level views are allowed only as aggregated summaries of wards.

Features must appear only in their respective role dashboards, as specified below.
