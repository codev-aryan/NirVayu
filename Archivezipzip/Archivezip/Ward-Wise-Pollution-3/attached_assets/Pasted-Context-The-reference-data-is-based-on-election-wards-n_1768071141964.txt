Context:
- The reference data is based on election wards (not zones)
- A ward boundary database (GeoJSON) already exists in the project
- An AQICN (WAQI) API key already exists in the environment variables
- AQI data is station-based, not ward-based

Goal:
Automatically compute and display election ward-wise AQI by matching
the existing ward boundary database with live AQI station data.

Tasks:
1. Load the existing ward boundary GeoJSON from the project files
2. Fetch live AQI station data for Delhi using the AQICN API
   - Read the API key from environment variables (do NOT hardcode it)
3. Extract AQI station coordinates (latitude & longitude) and AQI values
4. Match each AQI station to its corresponding election ward using
   point-in-polygon / spatial containment logic
5. Group AQI values strictly by ward identifier (ward_id / ward_name)
6. Compute ward-wise AQI using:
   - average AQI of stations inside the ward, or
   - nearest-station AQI if only one station is available
7. Bind the computed ward-wise AQI data to the existing dashboard components

Important corrections:
- Ensure each dashboard unit represents exactly ONE election ward
- Remove any zone-level or aggregated grouping behavior
- Use election wards as the only primary entity throughout the project

Technical requirements:
- Use JavaScript with fetch and async/await
- Perform all API calls and spatial computations in the backend
- Do NOT expose the API key to the frontend
- Frontend should fetch only processed ward-wise AQI data from backend APIs
- Update data dynamically without page reload
- Add loading and error handling
- Keep all existing UI, layout, and styling unchanged
- Ensure full Replit compatibility

Notes:
- AQICN API endpoint to use: /search/?keyword=delhi
- Station coordinates must be mapped to ward polygons to compute AQI
- Modify only logic where required; do not redesign the UI

Expected outcome:
- A fully functional election ward-wise AQI dashboard
- Accurate ward-level AQI computed from live station data
- Clean, readable, and well-commented code
